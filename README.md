# Lista Friends & Family · Downtown Studios

Página de la lista F&F de Downtown Studios (Torre 2 de Downtown Greenville): unidades con plano, superficies, precio F&F, evolución de precio hasta Lista, plan de pago, ubicación en el piso, vista desde cada unidad, video 360 y renders.

- `index.html`: la página completa (estilos, datos y lógica).
- `img/`: planos de las unidades, ubicación en planta y logos.
- `vistas/`: vistas desde cada unidad.
- `media/`: video 360 y renders.

Precios vigentes al 13/11/2026.
